# Nook 디자인 시스템

Nook은 생각을 정리하는 조용한 작업 공간을 지향한다. 정보 위계와 사용성을 먼저 두고,
색과 모션은 현재 상태를 이해하는 데 필요한 만큼만 사용한다.

## 레이아웃

- 데스크톱은 상단 탭과 벤또형 홈을 사용한다.
- 모바일은 불투명 하단 탭과 단일 열 작업 면을 사용한다.
- 홈은 생각 입력을 가장 큰 면으로 두고 책장과 이어갈 대화를 보조 영역에 배치한다.
- 대화는 읽기 폭을 제한하고, 질문 지도와 메시지 흐름을 분리한다.
- 생각 더미는 저장한 이야기, 이어갈 대화, 휴지통을 탭으로 구분한다.

## 색상

| 배경 / 카드 / 올린 면 | #F4F5F7 / #FFFFFF / #F1F2F5 | #14161A / #1E2126 / #262A30 |
| 본문 / 보조 / 흐림    | #17191C / #6B7280 / #9CA3AF | #F2F4F7 / #A2AAB5 / #79818C |
| 선 / 진한 선          | #E7E9ED / #D2D6DC           | #2A2E35 / #3C424A           |

강조색은 선택 상태, 포커스, 의미가 있는 짧은 강조면에만 쓴다. 브랜드 심볼의 세 색은
제공된 원본을 유지한다. 깊이는 그림자보다 배경 → 카드 → 올린 면의 명도 차로 만든다.

레거시 토큰은 아직 일부 라우트가 참조하므로 새 팔레트에 매핑해 유지한다.

## 타이포그래피와 형태

- SUIT 가변 폰트
- 본문 15–18px, 메타 12–13px, 주요 제목 27–34px
- 모서리 반경 20 / 16 / 12px
- 간격 8 / 14 / 20 / 26px
- 작은 글자에는 낮은 대비 색을 사용하지 않는다.

## 브랜드

- 앱 심볼: `public/nook-symbol.png`
- 텍스트 로고: `public/nook-wordmark.png`
- 조합 컴포넌트: `src/components/nook/wordmark.tsx`

원본을 다시 그리거나 폰트로 대체하지 않는다. 다크 테마에서는 텍스트 로고만 밝게
전환하고 심볼의 색과 타일은 유지한다.

## 책과 카드

책장과 책등은 “생각을 한 권의 이야기로 남긴다”는 제품 개념을 전달한다. 홈에서는
세로 책등을, 상세와 목록에서는 읽기 쉬운 카드를 사용한다. 책등에 임의의 색을 순환
적용하거나 장식적으로 기울이지 않는다.

이어갈 대화는 겹친 카드로 표시한다. 드래그 중에도 카드가 자기 그리드 영역을 벗어나지
않아야 하며, 버튼·키보드·스와이프가 같은 전환 상태를 공유한다.

생각 더미의 도구 줄은 왼쪽에서 보기 방식을 고르고 오른쪽에서 현재 목록을 편집한다.
선택 삭제에서는 체크박스 자리를 제목 여백과 분리하고 카드 전체를 선택 표적으로 쓴다.
홈의 이어갈 대화 수는 페이지에 보이는 카드 수가 아니라 실제 전체 개수를 숫자로 쓴다.

## 모션과 접근성

- 카드 전환과 내용 등장은 200–280ms 범위
- 저장 성공 전에는 완료 모션을 노출하지 않는다.
- `prefers-reduced-motion`에서는 이동 효과를 제거한다.
- 모든 주요 동작을 키보드로 수행할 수 있어야 한다.
- 포커스 링은 배경과 충분한 대비를 유지한다.
- 모바일에서 가로 스크롤을 만들지 않는다.
