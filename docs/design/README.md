# Nook 디자인 01 — 정리되는 작업 공간

2026-09-15 사용자 요청으로 이전 무드보드와 종이 소품·스크롤 소개 화면을 폐기했다. SEED React의 기존 입력·버튼을 유지하고 Pretendard 400/500/600을 사용한다.

## 큰 구조

- 데스크톱: 왼쪽 탐색 176px, 중앙 작업 면, 홈의 보조 안내 280px. 대화는 읽기 폭을 제한한다.
- 모바일: 하단 탐색과 단일 작업 면. 가로 스크롤 없이 입력·보관 동작을 유지한다.
- 생각 더미: 상세·목록 화면은 펼칠 수 있는 수평 텍스트 카드를 쓴다.
- **책등 표현은 유지한다 (2026-09-16 사용자 확정, 이전 "세로 책등 표현을 제거한다"를 뒤집음).** 제품 컨셉이 책상에서 생각을 정리하는 것이라 책장과 책등이 그 컨셉의 일부다. 홈에는 책등이 꽂힌 책장을, 상세·메뉴 안쪽에는 카드를 쓴다. 책등은 좁아서 한 화면에 여러 권이 들어가므로 카드 그리드 기준의 스크롤·드래그 계산을 책등에 적용하지 않는다.
- 되돌린 것은 책등이라는 표현이 아니라 vivid 시안의 **완성도와 맥락 없는 컬러감**이다. `nth-child`로 주황·라임·파랑을 돌려 쓰고 책을 기울이는 연출은 쓰지 않는다. 형태는 살리고 색은 상태와 행동에만 쓴다.
- 홈은 벤또 구성이다. 입력이 왼쪽을 통째로 쓰고 오른쪽에 조명·책장·이어갈 대화가 쌓인다. 메뉴는 좌측 사이드바가 아니라 **상단탭**이다.
- 라이트/다크를 모두 지원한다. 조명 토글이 테마를 바꾸고 선택은 기억된다. `<html>`을 `dark-only`로 고정하지 않는다.
- 로그인: 텍스트와 넓은 면을 사용하고 장식용 PaperArt를 제거한다.

세 색은 제공된 참고 팔레트에서 골랐다. 색상은 배경 장식보다 상태와 행동에 사용한다. 작은 글자에 낮은 대비의 색을 쓰지 않는다. 본문 16–18px, 메타 13–14px, 주요 제목 28–40px. 카드 모서리 18–24px, 간격 8/16/24/32px.

## 움직임

200–280ms의 카드 상승·내용 등장만 적용한다. 종료 제안은 실제 상태가 바뀌어 나타날 때 움직인다. reduced-motion에서는 제거한다. 저장 성공 전에 저장 애니메이션을 보여주지 않는다. 질문 경로 이동과 카드 보관 이동의 연속 애니메이션은 이번 범위에 포함하지 않았다.

## 검토와 범위

[nook-design-01.html](nook-design-01.html)은 API를 호출하지 않는 독립 시안이다. 예시 데이터가 표시되며 생각 쓰기/대화/생각 더미 전환, 카드 펼치기, 종료 제안 표시를 검토할 수 있다. 서비스 성공이나 실제 저장을 가장하지 않는다.

실서비스 페이지에도 공통 스타일과 레이아웃을 반영했다. 기존 API·보관 정책은 바꾸지 않았다. 실제 데이터의 미해결 상태 표시 확대는 데이터 계약과 별도 연결 검토가 필요하다.

타입·린트·빌드 검증을 수행했다. 브라우저가 localhost 접속을 ERR_BLOCKED_BY_CLIENT로 차단하여 실제 렌더링/모바일 터치/폰트 다운로드 검증은 아직 완료하지 못했다. 배포·운영 DB 변경·유료 모델 호출은 이번 작업에서 실행하지 않았다.

참고: Golden Suisse의 정보 위계와 Agrilo의 제한된 포인트 컬러. 삽입 영상은 재생 제한으로 원본 모션을 검증하지 못했다. 2026 동향에서 모션과 코드 기반 디자인 도구의 확대를 참고하되 유행 효과보다 작업 집중과 읽기 편의를 우선했다.
