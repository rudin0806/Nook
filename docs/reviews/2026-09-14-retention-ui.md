# 생각더미 보관 관리 기능

보관한 이야기·남겨둔 질문·휴지통 목록을 전환할 수 있다. 보관한 이야기는 확인 후 휴지통으로 이동하고, 휴지통에서는 서버가 허용하는 기한 내에 복원한다. 복원 기한은 서버의 purge_after를 한국 시간으로 표시한다. 별도로 보관한 질문은 삭제 확인 후 영구 삭제한다.

변경 요청은 기존 쿠키 인증 API를 사용한다. 처리 중에는 목록 전환·변경 버튼을 잠그고, 응답의 항목 ID와 상태를 검사한 다음 목록 첫 페이지를 다시 조회한다. 네트워크 오류로 처리 결과를 모르면 성공으로 표시하지 않고 목록 새로고침을 안내한다. 자동 재시도하지 않는다. 로그인 만료는 계정 연결 링크로 안내한다.

신규 클라이언트 계약 테스트 3개: 요청 경로·메서드·인증 쿠키, 로그인/만료/서버 오류와 재시도 금지, 다른 항목의 응답 및 잘못된 ID 거절. 타입·린트·프로덕션 빌드 검증. 실제 로그인 사용자의 데이터 변경 왕복은 별도 검증 전이다.

이번 범위는 기존 보관 데이터의 관리다. 세션 생성·종료 후 최초 보관 선택·대화 생성·자동 삭제 예약은 포함하지 않는다. 휴지통 문구는 복원 가능 기간만 표시하며 자동 삭제 예약이 이미 가동 중이라고 표현하지 않는다.
